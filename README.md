One monologue of about 100 words, spoken in a game by a fantasy villain who is secretly just very tired. The tiredness is never named: it lives in the trailing clauses, the small deflections gone nowhere, and a threat described like a chore on a long list. The speaker is the toll-keeper of Harrow's Neck, who charges crossings not in coins but in years, and has a chair, and a river, and all the time in the world for you to pay.

`main.ts` is a Node 22 TypeScript program (standard library only, no network, no secrets). It holds the monologue as a single string constant and writes it verbatim to `<outputDir>/entry.txt`, where `outputDir` is `$OUTPUT_DIR` when set and `/output` otherwise, creating the directory if missing. Output is deterministic; it also prints the word and character counts.

Verified counts: 100 words, 502 characters.

## Run it

```sh
OUTPUT_DIR=out node main.ts
```
